# 新疆鸟会队观鸟记录

2026 中国观鸟记录中心观鸟大年活动。

访问地址：https://ivanid.github.io/xinjiang-birding-2026/

本仓库保存可直接发布的网页、公开数据和完整 Excel 清单。数据来源：中国观鸟记录中心，队伍 1849，活动 100。页面显示原站统计更新时间；同步失败时保留上次成功的数据。

记录人来自队长导入表，仅在物种编号和首次记录日期同时吻合时显示；手机号形式的网名已打码。

GitHub Pages 使用 main 分支根目录。数据同步与 Excel 生成在队长本机的 bird-dashboard 项目中执行，再发布到本仓库；GitHub Pages 本身不自动采集数据。
